## 阶段一：机器人几何拓扑建模、参数测量与接触动力学标定

### 1.1 独立开发环境建立与前置依赖安装
为保证工程稳定与环境纯净，建立专属虚拟环境，锁定 MuJoCo 动力学引擎与数值计算库：
```powershell
# 1. 创建并激活 Python 3.11 独立环境
conda create -n wheel_leg python=3.11 -y
conda activate wheel_leg

# 2. 安装核心物理仿真与计算依赖
pip install mujoco==3.14.0 numpy==2.4.6 scipy==1.17.1 matplotlib stable-baselines3==2.3.2 shimmy==2.0.0
```

### 1.2 SolidWorks 几何参数精测与质量属性提取
在 SolidWorks 中对机器人进行 Defeature 简化，剔除内部螺丝、倒角等非功能特征后测量 19 项核心参数，填入 `LQR计算代码/parameter.py`：
* **机身全重**：总重 $189.36\text{ g}$（机身 $167.94\text{ g}$，单腿 $8.77\text{ g}$，单轮 $2.21\text{ g}$）；
* **轮距与轮径**：轮间距 $41.34\text{ mm}$，车轮半径 $R = 8.0\text{ mm}$；
* **质心偏置**：机体质心距离髋关节几何轴心具有向前 $3.28\text{ mm}$ 的物理偏置。

### 1.3 解决 URDF 装配缺陷与 MuJoCo MJCF XML 编写
使用 SW2URDF 插件导出运动学模型，并在转换为原生 MuJoCo `wheel_leg.xml` 时修复核心拓扑问题：
1. **修正左右腿非对称贴合**：消除装配图元中右腿与机身贴合面 $1.5\text{ mm}$ 的偏移缺陷；
2. **标定 12 微米高刚度接触动力学参数**：MuJoCo 默认接触软弹簧会导致 189g 车身轮子深陷地表 $6.14\text{ mm}$（占轮径 $77\%$），通过在 XML 中显式标定阻抗求解参数，将地面形变硬化至 $12\,\mu\text{m}$ 级真实刚性轮地接触：
   ```xml
   <geom friction="1.2 0.005 0.0001" solref="0.002 1.0" solimp="0.95 0.99 0.001 0.5 2" ... />
   ```
3. **命令行静态动力学校验**：
   ```powershell
   python -m mujoco.viewer --mjcf=model/wheel_leg.xml
   ```

## 阶段二：LQR 状态空间连续系统推导与工业级 C++ 工程落地

### 2.1 求解连续代数黎卡提方程（CARE）计算增益矩阵
1. **定义 10 维状态变量与 4 维控制输入**：
   * 状态向量 $x = [x, \dot{x}, y, \dot{y}, \theta_l, \dot{\theta}_l, \theta_r, \dot{\theta}_r, \phi, \dot{\phi}]^T$
   * 输入向量 $u = [T_{lw}, T_{ll}, T_{rw}, T_{rl}]^T$（左/右轮毂电机、左/右髋关节电机力矩）
2. **运行求解脚本导出增益矩阵 $K$**：
   ```powershell
   cd "LQR计算代码"
   python calculate.py
   cd ..
   ```
   * 求解产出 $4 \times 10$ 维状态反馈增益矩阵 $K$，严格满足左右轮驱动同模对称与左右差速差模反对称。

### 2.2 Python 快速原型闭环仿真与遥控测试
在 `test_balance.py` 中实现状态估计算法与双模式串级控制：
```powershell
python test_balance.py
```
* **控制操作指令**：
  * `↑` / `↓`：前进巡航加速与后退制动（目标速度 $0.08\,\text{m/s}$）；
  * `←` / `→`：差速转向与原地航向偏航；
  * `Space`：紧急软制动悬停自平衡；
  * `R`：重置仿真状态。

### 2.3 工业级标准 C++ 三层解耦架构编译与交付
针对硬件在环（HIL）规范，编写 `interface`（底层驱动抽象）、`controller`（算法逻辑解耦）、`runner`（仿真循环调度）三层 C++ 架构，并生成自包含二进制程序：
```powershell
# 1. 创建构建目录并生成 CMake 工程
cmake -B build -G "MinGW Makefiles"

# 2. 编译原生可执行文件
cmake --build build --config Release

# 3. 运行 C++ 独立仿真环境
./build/wheel_leg_sim.exe
```

## 阶段四：SCT-RRL 滑移耦合能量储罐研发与微观调参

### 4.1 核心调参痛点与动力学失稳根源
在面对连续冲击与剧烈起伏时，残差策略网络容易出现两大隐患：
1. **高频力矩颤振与作动器发热**：残差网络在越障瞬间易输出 >10Hz 的交变剧烈控制力矩；
2. **车轮打滑诱发的能量耗散与失稳**：单轮空转打滑时电机持续做功但无法产生有效牵引，直接破坏倒立摆系统的能量无源性（Passivity）。

### 4.2 滑移耦合能量储罐（Slip-Coupled Energy Tank）数学调参
引入无源能量储罐机制，构建状态依赖的动态能量账户 $E_t$：
$$E_{t+1} = E_t + \Delta t \cdot \left[ \beta (E_{max} - E_t) - P_{slip}(t) \right] - \Delta W_{action}$$

#### 【关键工程参数标定矩阵】
| 参数符号 | 物理含义 | 最终标定值 | 调参调试心得与物理约束 |
| :---: | :--- | :---: | :--- |
| $E_{init}$ | 储罐初始安全能量预算 | $6.5 \times 10^{-4}\text{ J}$ | 对应小车安全抗扰裕度，过小会导致起步受限，过大失去监控意义 |
| $E_{min}$ | 绝对能量下限阈值 | $0.5 \times 10^{-4}\text{ J}$ | 防止数值下溢；当储罐触及下限时强行将残差动作缩放至 0 |
| $E_{max}$ | 储罐能量储能上限 | $8.0 \times 10^{-4}\text{ J}$ | 避免长时间平路累积过多无用能量预算 |
| $\beta$ | 储罐自然回补速率系数 | $0.0035$ | 平稳行驶时平缓充能；过大会导致对打滑反应迟钝 |
| $\gamma$ | 滑移能量惩罚耗散系数 | $0.016$ | 轮地发生线速度差时加速抽干储罐，迫使策略收敛降速 |
| $v_{dead}$ | 切向滑移速度过滤死区 | $0.003\text{ m/s}$ | 滤除 MuJoCo 触地瞬间微米级弹性形变产生的虚假滑移 |
| $\tau_{slip}$ | 滑移功率一阶低通滤波时间常数 | $0.040\text{ s}$ | 平滑瞬态微小毛刺，避免控制力矩突变抖动 |

### 4.3 二分法无源性投影求解器（Passivity Bisection Projection）
当策略网络请求的残差动作能耗 $\Delta W_{action}$ 超过当前可用能量预算 $E_t - E_{min}$ 时，求解器在 $[0, 1]$ 区间内进行 12 次二分法收缩搜索最佳缩放因子 $\alpha^*$：
$$\alpha^* = \arg\max_{\alpha \in [0, 1]} \left\{ \alpha \;\middle\|\; \Delta W(\alpha \cdot a) \le E_t - E_{min} \right\}$$
通过投影强行约束输出力矩在无源安全空间内，彻底消除高频颤振。

### 4.4 4.0m 赛道 SCT 动态消融验证
```powershell
python rl/eval_sct.py
```
* **定量产物**：生成微观储罐能量曲线图 `rl/evaluation/legacy_archive/phase3_4m_sct_energy_tank/sct_tank_dynamics.png`；
* **消融结论**：车轮切向滑移降低 $20.2\%$，>10Hz 高频力矩功率大幅削减 $29.7\%$。

## 阶段五：10.5m 复合极限制图研发与三算法全长对比大考

### 5.1 10.5m 极限制图规范（Mega S-Curve Mountain Track）
将原有 4.0m 单一地形拓展为涵盖 8 大极限特征地貌的 10.5m 终极测试场：
* **数字高度图规格**：网格分辨率 $2560 \times 256$，最大绝对高程 $45\text{ mm}$；
* **八大核心地貌分区**：
  1. `0.0m ~ 0.5m`：平地起步校准区；
  2. `0.5m ~ 1.5m`：高密度双边莫古尔正弦波浪群（峰值 $2.0 \to 3.8\text{mm}$）；
  3. `1.5m ~ 3.0m`：重型交错单侧隆起障碍群（凸起 $+4.2\text{mm}$）；
  4. `3.0m ~ 5.0m`：连续复合 S 型立体大弯道（转弯半径 $R \ge 1.62\text{m}$，叠加 $3.5\text{mm}$ 起伏波浪）；
  5. `5.0m ~ 6.5m`：高难度爬坡段（坡长 $1.5\text{m}$，爬升净高程 $+35\text{mm}$）；
  6. `6.5m ~ 7.5m`：山顶高台与交错突起障碍带（维持 $35\text{mm}$ 高台平原）；
  7. `7.5m ~ 8.8m`：阶梯式落差断崖下坡（$35\text{mm} \to 18\text{mm} \to 0\text{mm}$ 陡变断崖）；
  8. `8.8m ~ 10.5m`：落地重载连续搓板路冲击群与终点 $10.0\text{m}$ 精准刹车停驻区。
