## 二、 第一阶段：动力学建模、LQR 现代控制与 C++ 标准工程实现

### 2.1 状态空间方程建立与连续代数黎卡提方程求解
将五连杆轮腿结构在工作点附近等效为带主动髋关节的双轮倒立摆系统，建立 10 维状态变量与 4 维输入变量：
* **状态向量** $x = [x, \dot{x}, y, \dot{y}, \theta_l, \dot{\theta}_l, \theta_r, \dot{\theta}_r, \phi, \dot{\phi}]^T$（位移、偏航、双腿摆角、车身俯仰角及其一阶导数）；
* **控制输入** $u = [T_{lw}, T_{ll}, T_{rw}, T_{rl}]^T$（左轮、左髋、右轮、右髋电机力矩）；
* 基于欧拉-拉格朗日方程在直立平衡点进行一阶泰勒线性化，导出连续时间系统状态空间矩阵：
  $$\dot{x} = A x + B u$$
* 定义二次型性能指标泛函：
  $$J = \int_0^\infty \left( x^T Q x + u^T R u \right) dt$$
* 求解连续代数黎卡提方程（CARE）：
  $$A^T P + P A - P B R^{-1} B^T P + Q = 0 \implies K = R^{-1} B^T P$$
* 解算出的状态反馈增益矩阵 $K$ 严格呈现出正交对称性：左右轮驱动对纵向前进为同模正反馈，对偏航航向为差模负反馈，左右髋关节对俯仰倾角具有高达 $-9.986$ 的强力负反馈阻尼。

### 2.2 12 微米超高刚度接触动力学突破
在 MuJoCo 默认接触参数下，由于微型小车接触刚度过软，小车轮子陷入地面深达 $6.14\text{ mm}$（占轮半径 $77\%$）。本工程标定高刚度阻抗方程：
`<geom friction="1.2 0.005 0.0001" solref="0.002 1" solimp="0.99 0.999 0.0001 0.5 2"/>`
通过隐式欧拉积分器将沉降深度压缩至 **$0.012\text{ mm}$（12 微米）**，彻底根除轮体穿模。

### 2.3 串级前倾外环与反作用力矩佯谬攻克
两轮倒立摆系统存在**反作用力矩佯谬**：若机身保持垂直直立，电机施加正向推力矩时，定子作用于车身的反作用力矩会迫使车身后仰跌倒。
为实现自主巡航，我们构建了“**串级拓扑结构**”：
1. **外环（纵向运动规划）**：根据当前速度误差 $v - v_{\text{cmd}}$ 或位置误差 $x - x_{\text{cmd}}$，通过达朗贝尔惯性力平衡解算出**目标前倾角** $\theta_{\text{target}}$；
2. **内环（高频状态反馈）**：驱动轮跟踪该前倾角误差 $\theta - \theta_{\text{target}}$，小车身体自然前倾、重心前移，通过重力分量转化为持久的前向加速度！

### 2.4 C++ 三层解耦架构落地
严格遵循工业级规范，工程拆分为三大无耦合独立模块：
* **`interface.cpp` (接口层)**：负责 MuJoCo 底层传感数据地址缓存、四元数转欧拉角、前向速度投影以及 $0.05\text{ N}\cdot\text{m}$ 执行器硬件级硬限幅；
* **`controller.cpp` (控制层)**：**100% 纯数学逻辑，零 MuJoCo/系统 API 依赖**，可无缝移植至 STM32 / ROS2 主控；
* **`runner.cpp` (运行调度层)**：负责 1000Hz 物理主循环与 60fps GLFW 3D 渲染窗口同步。
* 打包了自包含便携运行套件，支持脱离编译环境双击运行 `bin/wheel_leg_sim.exe`。

## 三、 第二阶段：创新点确定与 PRCC 残差顺应强化学习

### 3.1 核心问题：为什么平地 LQR 遇到起伏会失稳？
在 4.0 米起伏路面测试中，我们发现了纯 LQR 的根本瓶颈：
* 遇到单侧 $3.5\text{mm}$ 高度凸起时，由于两侧车轮高低不平，机身被动产生剧烈的横滚晃动（最大侧倾角突破 $6.32^\circ$）；
* 左右髋电机锁死在固定角度，小车只能像“独轮推车”一样被地面生硬地颠起；在车轮跨过凸起悬空的瞬间，法向正压力丧失，驱动轮发生严重空转打滑。

### 3.2 PRCC 架构创新设计 (Prior-Residual Compliance Control)
我们拒绝易烂尾的端到端裸控，敲定“**经典先验负责高频平衡，强化学习负责接触顺应**”的协同架构：

```
                    [盲走本体感知流 69维 (堆叠3帧)]
                                  │
                                  ▼
                    [PPO 残差策略网络 Policy (50Hz)]
                                  │
             ┌────────────────────┴────────────────────┐
             ▼                                         ▼
   [残差设定点 (3维)]                          [虚拟刚度比 (1维)]
   - 俯仰修正: Δθ_pitch                          - 悬架软硬: k_scale
   - 对称升降: Δq_hip                                  │
   - 差动侧倾消除: Δq_roll                              │
             │                                         │
             ▼                                         ▼
      (叠加至先验设定点)                       [Kp_hip = Kp0 * k_scale]
             │                                         │
             └────────────────────┬────────────────────┘
                                  ▼
                 [底层经典串级自平衡控制器 (1000Hz)]
                                  │
                                  ▼
                 [4路高频执行器电机输出力矩]
```

#### 创新核心要素：
1. **差动主动侧倾消除（Differential Roll Cancellation）**：
   $$q_{\text{lh\_target}} = q_0 + \Delta q_{\text{hip}} + \Delta q_{\text{roll}}$$
   $$q_{\text{rh\_target}} = q_0 + \Delta q_{\text{hip}} - \Delta q_{\text{roll}}$$
   当右轮碾过凸起时，策略输出 $\Delta q_{\text{roll}} > 0$，使得右腿主动上收、左腿适度伸长，**地面虽高低不平，机身却始终保持一字水平横向稳定**！
2. **虚拟阻抗顺应自适应（Virtual Compliance Modulation）**：
   髋关节弹性刚度随地面粗糙度动态调节 $K_{p} = K_{p0} \cdot k_{\text{scale}} \in [0.7, 1.3]$，碰撞瞬态软化悬架，平稳路面锁紧悬架。
3. **盲走本体感知设计（Proprioceptive Observation）**：
   不提供前方地形雷达高度图。观测由 3 帧历史的欧拉姿态、角速度、线速度、轮腿编码器状态及上步动作堆叠而成（单帧 23 维，共 69 维），逼迫网络从接触动力学响应中隐式感知地形冲击。
4. **动作能量与平滑度正则化奖励**：
   $$R = R_{\text{track}} + R_{\text{alive}} - 10.0 \phi^2 - 2.0 \theta^2 - 5.0 R_{\text{slip}} - 5.0 \ddot{z}^2 - 0.05 ||a||^2 - 0.05 ||\Delta a||^2$$
   对残差动作施加模长二次型惩罚，确立了“**平地残差休眠归零、越障凸起主动吸收**”的主从协同准则。

### 4.3 经典学术洞察：自平衡-主动顺应性动态权衡（Balance-Compliance Trade-off）

在评测中，我们观察到两项极其深刻的轮腿机器人控制理论现象：
1. **纯 LQR 的“刚性卡车”减速效应**：
   纯 LQR 下两条腿被高刚度 PD 锁死在刚性几何构型上。当单侧车轮猛烈撞击 $4.8\text{ mm}$ 弧面减速垄时，刚性冲击直接转化为反向阻力，导致小车频繁产生瞬间失速并发生剧烈俯仰颠簸。在 25 秒内，LQR 仅行驶了 $5.05\text{ m}$。
2. **PRCC-RL 的“空气悬架”顺应推进效应**：
   PRCC-RL 策略网络自适应学习到了动态降刚度（$k_{\text{scale}} \approx 0.72$，相当于刚度软化 $28\%$）与微动柔顺补偿。在碾过减速垄时，悬架如弹性弹簧般将垂直刚性冲击吞吐吸收，整车垂直沉浮降低 **$6.7\%$**；同时轮地贴地性更佳，动力不中断，25 秒行驶达 **$6.10\text{ m}$**（相比 LQR 提速 **$+20.8\%$**）！
3. **轮地滑移率差异的工程必然性**：
   PRCC-RL 在吸收颠簸时，腿长的轻微伸缩（$\Delta q$）会瞬时改变轮毂在空间中的切向速度，且主动悬架为了消除振动会主动调节轮电机力矩。这种极微小的轮速波动（仅增加 $1.4\text{ mm/s}$）是主动减震系统的正常物理代价，换取的是显著更顺畅的越障通过速度与更平顺的机身起伏。

## 五、 关键工程踩坑与技术沉淀（Lessons Learned）

在本次极限攻坚中，我们踩平了多个具有极高工程价值的隐蔽大坑，全部沉淀为技术资产：
1. **工况失配与评测盲区（Benchmark Pitfall on Flat vs Rough Ground）**：
   - *问题*：最初评测在平地测试时，发现 RL 腿部有轻微浮动，而纯 LQR 纹丝不动，甚至误判 LQR 更稳。
   - *洞察*：在平地上，LQR 本来就是数学最优解；主动悬架的威力只有在恶劣越野工况下才能体现。评测基准必须精准覆盖特征路段，切忌用“高速公路的平稳性”去否定“越野悬挂的避震价值”。
2. **轮地滑移率的运动学几何速度耦合假象**：
   - *问题*：直接用机身线速度减去轮子线速度算滑移率，导致 RL 伸缩腿部时被误判为“打滑严重变差”。
   - *解法*：推导轮毂中心真实运动学方程 $v_{\text{hub}} = v_{\text{body}} + \dot{q}_{\text{hip}} L_{\text{leg}} \cos q_{\text{hip}}$，从物理公式上彻底解除了腿部摆动与纯滚动的速度耦合。
3. **先验与强化学习目标速度冲突导致的自相搏击与高频抽搐**：
   - *问题*：最初训练的策略视觉上看起来比 LQR 慢，且车体带有 50Hz 高频抽搐微抖。
   - *机理*：环境设定的 $v_{\text{target}} = 0.10\text{ m/s}$ 远低于先验控制器自身的巡航速度（$\sim 0.20\text{ m/s}$），策略网络为了贪婪获取速度奖励，被迫高频输出后仰指令进行主动“刹车”，导致强化学习与先验 LQR 剧烈互搏撕扯。
   - *解法*：将强化学习目标速度统一对齐至 $0.16\text{ m/s}$，收缩俯仰残差权限（$\pm 0.005\text{ rad}$）专注于纵向阻尼，引入动作平滑度变化率惩罚（$-0.20 \|\Delta a\|^2$），彻底消除微振，实现了两车并排以 $0.16\text{ m/s}$ 高速冲锋且 RL 越障提速 $20.8\%$！
4. **Windows 平台多进程强化学习（SubprocVecEnv）管道死锁**：
   在 Windows 上调用子进程采样时，由于子进程重复加载 MuJoCo 底层 C 动态库，导致标准流输出与 IPC 管道互锁卡死。工程解法是切换为单进程受控高稳容器 `DummyVecEnv`，并释放底层 PyTorch 的 8 线程多核加速，在消除死锁的同时跑满 **350 FPS**。
5. **微型倒立摆残差动作饱和与 Bang-Bang 震荡**：
   微型倒立摆惯性极小，若俯仰残差给到 $\pm 2.8^\circ$，相当于一脚油门踢翻小车。工程解法是将俯仰残差约束在极微小温和的 $\pm 0.28^\circ$、差动横滚残差设为 $\pm 4.6^\circ$，并在奖励中引入动作模长能量惩罚，实现主次分明的高雅控制。
